Kind: software. A working tool for running an AI development team, not a marketing site.

Direction: a calm workbench. Neutral paper and graphite surfaces, one green accent for actions and
"approved", amber for "draft". An editorial serif (Instrument Serif) for titles, DM Sans for the
interface, and the system monospace font for code, file names and IDs. Dark mode uses the same hierarchy.

Layout: sidebar (projects → versions) | workspace. A run shows its header (version trail, status,
passes, Download .zip, run ID), then a report column (Summary / Plan / Review as native <details>)
beside a sticky file viewer (tabs, line numbers, highlight.js, copy and download per file).
Below 1100px the report and files stack; below 860px the sidebar becomes a drawer.

Truthfulness: no fake streaming or step progress. While the team works, the UI shows the roles and
a real elapsed timer. Errors keep the draft, and POSTs are never retried automatically.

Motion: a short entrance, a pulse on the working roles, and button feedback.
prefers-reduced-motion turns all of it off.
